# Clearance Ledger

Phone app for clearance retail arbitrage. Scan a barcode, get the item and an estimated sell price from online listings, type the shelf price, and see Buy / Thin / Pass after fees, tax and shipping. Log your haul and see which items bundle well.

Open on an iPhone in Safari: https://javtsplayground.github.io/clearance-ledger/ then Share > Add to Home Screen.

Price estimates are current online listing prices, not sold prices. Photo ID is optional and uses your own Ollama over Tailscale (see SETUP.md). Everything is stored on the phone only.

Tests: `npm test`
